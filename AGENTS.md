# Development

Build a small standalone MCP bridge using OpenAI's primary protocol documentation and installed components. Do not copy code from community computer-use wrappers or depend on a nested coding agent.

Keep approvals explicit, native permission requests intact, exact bundle-ID matching, live schema validation, sequential actions, and no automatic mutation retries. Never log private app content, screenshots, credentials, or user environment variables. Do not introduce a JavaScript execution tool.

Validation: `npm run lint`, `npm run typecheck`, `npm run build`, `npm test`. Live desktop tests require explicit authorization and `MAC_COMPUTER_USE_LIVE=1`; they are not part of ordinary tests or CI. Use only harmless Calculator interactions for the smoke test.

Do not publish screenshots or private local paths. Keep public documentation clear that this is independent, experimental, and not an OS sandbox.
